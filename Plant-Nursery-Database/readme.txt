Plant Nursery Database created by Jackie Tong and Duong Dinh.

This web user interface allows the user to view the SQL table of items based on Item ID
and name. The user is also able to perform the following operations: insert a new item, 
update an item based on ID, and delete an item based on ID.

The code for each operation is written in PHP and is based off of the demo files given. 
We wrote the script for displaying ITEM details based on ID
on our own, as we had trouble reading the contents of the table with the demo code.

Each script is written in PHP and to run it, put the code files into a folder and put
that folder into the "htdocs" directory where XAMPP is located. In XAMPP, start up mySQL 
and Apache and load up the database. On a web browser, go to http://localhost/ + the name
of the folder containing the PHP scripts in the "htdocs" folder. Click on whichever 
action you want to run.


The Scripts document is the list of queries used in the Query-Functions document. 
The Query-Functions document showcases complex SQL queries for data analysis. QV0 in the former 
document will correspond to the QV0 in the latter document.
